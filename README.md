# BusinessPay Marketing Website (`BusinessPay-Website`)

Official public marketing website, product landing page, and interactive AR acceleration ROI calculator for the **BusinessPay B2B AR & Early Payment Accelerator** platform.

---

## 🚀 Features

- **Product Landing Page**: Hero section showcasing AR automation and cash acceleration benefits.
- **Interactive ROI Calculator**: Real-time slider calculating DSO reduction and accelerated cash flow (`acceleratedCash = AR * (daysSaved / 365)`).
- **Subscription Pricing Tiers**: Growth ($499/mo), Pro ($1,299/mo), and Enterprise ($2,499/mo) plan breakdown.
- **Lead Capture Demo Modal**: Prospect demo request form for inbound sales pipeline integration.

---

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build
```
